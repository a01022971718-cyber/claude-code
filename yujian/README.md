# 屿见 · v0.19

> **v0.19 · 造物台 + 体素美术圣经**
> - **造物台**（方块岛左上角「造物台」）：自由造任何东西——任意多块、任意大小的长方块，任意颜色，可旋转；选择 / 添加 / 上色 / 擦除，拖彩色手柄改大小，左右对称，长按吸色，撤销重做；任意几块编成部件，设关节点和动作（走路摆、来回摆、扇动、旋转、浮动、随风摆、伸缩），播放预览。模板（四足小兽、鸟、树、花、水母、小屋）只是捷径，也可以从空白开始。
> - **带回六边形岛**：保存时选用途（动物 / 植物 / 建筑摆件）、行为（走、跳、飞、游、漂浮、不动）和大小，回到六边形岛，建造栏「✦ 我造的」里直接摆；动物按行为在附近活动，部件按动作动。同一造物共用模型并合批绘制。
> - **自动原版手感**：每块自动圆角（按大小分三档）、底部压暗、顶面略亮；开「色组」的块在几级深浅里自动交错。
> - **体素美术圣经**替换原来的造物手册：以最早那批原版体素素材为标准，写明素体规则（大小按部位、先大后小、每部位一组颜色、大面积深浅交错、允许错位、会动的做成部件）和原版拆解。AI 造岛的提示词同步换成这份。

> **v0.18 · 方块岛（第一阶段可玩原型）**：岛屿菜单 →「方块岛（试玩）」进入，菜单 →「回到六边形岛」返回，两边各自存档。
> - 192×192 格、高 64 层的方块世界，自然岛（沙滩、草地、丘陵、岩山、三种树）或平坦岛；30 种原创方块（地形、木材、石材、屋顶、玻璃、植物、灯具、装饰），颜色来自《造物手册》色板，花纹由着色器程序生成。
> - 只画露在外面的面；角落自然变暗；方块边缘柔和倒角感；天空、阳光、阴影、雾和六边形岛同一套。
> - 操作（俯视为主）：浏览 / 放置 / 拆除 / 吸管 / 替换；拿着笔时单指点 = 落子（按下先显示幽灵方块，抬起才放下），单指拖 = 连续摆或连续拆；长按 = 吸取；双指转视角、缩放、平移；右侧剖切滑杆看屋里；撤销 / 重做 100 步；自动保存（压缩后约 40KB）。
> - 菜单里可打开帧率显示（帧率、最慢一帧、三角形、绘制次数、像素比），用于真机测速。

> **v0.17 · 按人眼视觉分级渲染**：远近切换不再按固定距离，而按“在屏幕上占多少像素”判断——第一视觉（镜头附近、看得清细节的范围）完整渲染，往外依次换简化版本，人眼分辨不出的细节不画。
> - 地面：远处地块换成 1/9 三角形的粗地面（顶点和细地面对齐，接缝不裂）。
> - 树：完整树冠的三角形在屏幕上小于约 4 像素就换简化树；动物和小件屏幕高度不到约 40 像素就换减面模型。
> - 草叶：第一视觉内满密度，往外随屏幕大小递减（最少留三成撑住颜色）。
> - 117 块地的大岛、超高档、满细节、按手机实际分辨率（像素比 2.77）测：每帧三角形 俯瞰 41 万、中景 38 万、近景 40 万（v0.15 是 78 万 / 111 万 / 88 万）。

> **v0.16 · 性能专项第一步：砍掉看不见的面**（117 块地的大岛、超高档、满细节，每帧三角形：俯瞰 78 万 → 46 万，中景 111 万 → 40 万，近景 88 万 → 53 万；画面基本不变）
> - 阔叶树树冠从 8–11 个叠在一起的球改成一层外壳（轮廓不变），每棵 1716 → 416 个三角形；松树每层 16 → 12 个尖，714 → 546。
> - 远处的动物、建筑小件、蝴蝶蜜蜂小鸟、海里的鱼和珊瑚换成自动减面的简化模型（顶点聚类，颜色和动画属性都保留；正反两面分开，避免薄片光照出错），镜头拉近才用完整模型。
> - 草、麦子、花每帧有硬预算（按植被档位 16 万–60 万个三角形），超了就整体均匀变稀。

> **v0.15 · 造物手册（SOP）+ AI 审图 + 建造栏分类**
> - **造物手册**：一份美术标准作业流程，游戏内可看（岛屿菜单 / AI 造岛面板 →「造物手册」）。内容是七步作业法（定题 → 找底子 → 定轮廓 → 定比例 → 配色 → 点缀 → 生成与审图）、形态与底子、比例尺、50 色色板、审图清单，以及用到的全部技术。同一份内容原样写进 AI 的提示词：换一个人、换一个模型，照着做出来也是同一个风格。
> - **风格不再脱节**：AI 造的树、松、椰子、灌木、芦苇直接用原有素材当底子（同样的噪声起伏、软体积、下暗上亮的顶点色），只换轮廓（高瘦 / 矮宽 / 垂枝）和颜色；所有颜色吸附到色板；尺寸按比例尺夹值；动物改成和原有动物一致的小眼睛、口鼻、下暗上亮。
> - **AI 参与画图**：① AI 按手册设计配方 → ② 游戏生成模型，和原有素材同比例并排渲染对比图（上排植物、下排动物）→ ③ 把对比图交给能看图的模型，按清单打分、写意见、改配方 → ④ 你看过初稿和修改稿后再决定放进岛里。
> - **建造栏分类**：每一类顶上有小分类标签（岛屿：草木 / 山石 / 田园 / 水边；植物：树木 / 花草 / 岩石；动物：陆地 / 水边 / 天上；建筑：地标 / 生活 / 海上），AI 造的东西另有「✦ AI 造物」一栏。

> **v0.14 · AI 造物**：AI 造岛不再只是用游戏里已有的素材摆岛，而是**创造游戏里没有的新东西**——新生态（地块配色、起伏、草色、花色、长什么植物）、新植物（树、针叶、棕榈、灌木、蘑菇、花、仙人掌、水晶、芦苇九种形态 × 七种树冠 × 果实/花/斑点/发光点缀）、新动物（体型、腿数、头、眼、耳、角、尾、翅膀、花纹，走/跳/飞/游/蛇行五种习性和栖息地）。AI 只给出“造型配方”，游戏现场生成 3D 模型（经典和体素两套主题各有一种造法），新物种会住进岛上、出现在建造栏里（名字前带 ✦），随存档保存，换岛也保留。AI 造岛面板有三种模式：生成新岛 · 创造新物种 · 改造这座岛。

一款治愈系 3D 海岛游戏。打开就是一座完整渲染的海岛（自由画布）：随意加地块、种植物、放动物和建筑、换海水和时段；在草地上放地块时，有机会冒出泉水，发现溪流和池塘。

另有一套经营玩法（资源、目标、地块卡、委托、地标同伴），在设置里打开，默认关闭：玩家从一块小岛出发，用三选一的地块卡把岛铺向远方的地标；每点亮一座地标，就有一位新同伴搬到岛上。地图没有边界。

手机浏览器横屏体验最好，竖屏也能玩。

## 怎么运行

```bash
npm install
npm run build          # 生成 dist/index.html（单文件，脚本已内联）
```

直接用浏览器打开 `dist/index.html` 即可，不需要服务器。开发时用 `node build.mjs --dev`，会生成不压缩、外链 `game.js` 的版本。

## 自由画布（默认）

- **界面只占四个角**：左上岛屿菜单（换新岛：样张岛 / 空白小岛），右上时间、镜头、拍照、设置，右下建造按钮（点开后分类沿弧线展开），左下撤销和擦除（建造时才出现）。不操作 4 秒后界面自动淡出，碰一下屏幕就回来。
- **能放的东西**（`src/catalog.js`）：岛屿 9 种地形 + 溪流、池塘（发现后解锁）；植物 8 种；动物 4 种（会自己走动）；建筑 8 种 + 海面上的小船、浮标；海洋 3 种海水 + 唤来鲸、海豚跃水；天空 6 个时段。
- **稀有生态的发现**（`src/discovery.js`）：在草地上放地块时有机会冒出泉水。第 2 块草地必出；之后每块 6%，第 10 块起每块加 8%，第 18 块必出；清晨和黄昏翻倍，挨着水系再加 12%；没拿到的类型优先出。保底进度显示在岛屿栏顶部。经营玩法里放草地也会触发（规则上仍是草地，外观变成溪流或池塘）。
- **镜头**（v0.9 重做，`src/camera.js`、`src/camdock.js`）：
  - 触屏：单指拖动移动；**双指一起左右拖 = 转视角，上下拖 = 改俯角**；双指张开 / 捏合 = 拉近 / 拉远（同时扭转可旋转，中点移动会平移）。两指怎么动由开头 10px 判定，判定后整次手势不变，缩放和转视角不会互相干扰。
  - 电脑：左键拖动移动，右键（或中键、Shift+左键）拖动转视角和改俯角，滚轮缩放；键盘 WASD / 方向键移动、Q/E 旋转、R/F 抬高 / 放低、+/- 缩放。
  - 镜头面板（右上角镜头按钮，拍照时自动出现）：俯瞰、斜看、平视、特写四个预设机位，自动环绕，复位，俯角滑条，视野（窄 / 标准 / 广）。
  - 能拉到约 1 个单位的特写（看清小动物和村民），也能压到 3° 的平视；镜头不会钻进地面或海面；镜头绕着转的点贴着焦点下方的地面（以前固定在草地高度，看沙滩、海面时会偏）。
  - 缩放联动俯角（设置 → 镜头里可关）：拉近时慢慢放低成侧视，拉远时抬高成俯瞰；拉近时视野也自动放宽一点。
  - 拖动跟手：按住的那一点跟着手指走；镜头很平、手指指到天边时改按屏幕距离换算，不会一下甩出很远。
  - 设置里新增「镜头」页：视野、缩放联动俯角、转动灵敏度，以及操作说明。
- **AI 造岛入口**（v0.12）：左上角「AI造岛」按钮；可以生成一座新岛，也可以改造现在的岛（把当前布局发给模型，没提到的部分保留）。
- **岛民是“屿灵”**（v0.11，`src/hq/sprite.js`）：岛上的居民和渔夫不再是人，而是“活过来的小地块”——糯米色的六边形团子（和地块同一个形状），头顶盖着一片地表、长着各自的标志：草（嫩芽）、林（小松树）、花、麦（麦穗）、海（贝壳）、岩（石堆）。圆眼睛、腮红、小短脚，走路一蹦一蹦（落地压扁、腾空拉长）。造型为本项目原创。
- **大模型（AI）**（`src/ai.js`）：设置 → AI 里选服务商、填 API 密钥（只存在本机），可测试连接。Claude 走官方 SDK；OpenAI、DeepSeek、通义千问、智谱、Kimi、豆包、Gemini、OpenRouter、本机 Ollama 和任何 OpenAI 兼容接口走通用的 `chat/completions` 请求（“自定义”里填接口地址和模型名）。有的服务商不允许从浏览器直接访问，这时要填自己服务器的转发地址。
  - AI 造岛：岛屿菜单 → AI 造岛，用一句话描述，模型按六边形坐标返回布局（结构化输出约束成合法 JSON，再清洗：去重、限量、物件必须落在地块上），生成一座新岛。
  - 岛民说话：没拿工具时点一下村民，他按此刻在干什么说一句话；没配置 AI 时用内置台词。
  - 默认模型 `claude-opus-5-5`，开启了服务端兜底（模型因安全原因拒绝时自动换模型重试）。正式上线请用自己的服务器转发请求，不要把密钥放进客户端。SDK 让单文件包体增加约 400KB。
- **首次引导**：第一次进画布时依次提示拖动、旋转、建造，做到一步换下一步，可以跳过。
- **存档**：和经营玩法分开（`yujian_canvas_v1`），所有操作都能撤销。

## 经营玩法（设置里打开）

- **放地块**：手里 3 张卡，每张有价格。选卡 → 点亮起的格子预览（显示产出和相邻加成）→ 再点一次确认。地块从海里升起，结算资源。
- **地块**：草地、森林、山、菜园；接通风车后解锁麦田，接通灯塔后解锁渔港（只能放海边，带栈桥和渔船）。
- **收获**：森林、菜园、麦田、渔港可以点击收获，之后要等几小时重新长好，离线也计时。
- **地标与同伴**：风车（磨坊主阿穗）→ 灯塔（守塔人老汀）→ 钟楼（敲钟人小满）→ 之后是不断生成的远方地标和旅人。每座地标让资源上限 +10。
- **目标**：12 个主线目标兼做新手教学，做完后自动生成长期目标（接通下一座地标、岛屿规模、累计收获、委托）。
- **每日内容**：同伴委托（每天凌晨 4:00 刷新 3 个）、漂来的补给箱、作物重新生长。
- **激励视频（模拟）**：换牌、委托奖励翻倍、全岛立即长好。只做加成，资源用光时会免费送一张卡，不靠广告解围。
- **装饰**：16 种内置装饰，可以摆放、旋转、移动、收起、撤销。
- **玩家素材**：上传图片或低模，自动按标准检查、给出修改方法、一键修复，通过后转换成游戏风格的模型摆到岛上（见下）。
- **拍照**：隐藏界面，拖动构图，可以调时间拍黄昏和夜景。
- **存档与埋点**：自动存在本机浏览器；关键事件记录在本机，设置里可以查看和复制。

## Android 安装包

`android/` 是一个原生 Android 壳：全屏 WebView 加载打包好的单文件游戏（`dist/index.html` 放进 APK 的 assets），存档保存在手机本地，AI 功能可以联网。

- 打包：`android/build-apk.sh`（需要 Node、JDK 17+、Gradle 8.13+、Android SDK 的 `platforms;android-35` 和 `build-tools;35.0.0`），输出 `dist/yujian-<版本>.apk`。
- 包名 `com.yujian.island`，最低 Android 7.0；全屏沉浸、屏幕常亮、横竖屏跟随系统旋转设置；返回键把游戏切到后台，不丢进度。
- 签名用的是仓库里的测试密钥（`android/keystore/yujian-dev.jks`，密码 `android`），每次打的包都能覆盖安装。正式上架应用商店要换成自己的签名，且不要提交进仓库。
- 图标是原创的六边形小岛（`android/icon/icon.svg`）。

## 实时渲染

游戏默认用高画质画面，“极高”档和下面的“高画质样张”参数一致（草和花的密度、阴影、后期都相同）；“低”画质保留原来的低多边形画面（低画质下自由画布摆的植物、动物、建筑不显示）。

- **水系**：溪流地块的河道会和相邻的溪流、池塘连起来，入海处成瀑布（带水雾和落水白沫）；池塘有睡莲、芦苇、香蒲、野鸭、青蛙、蜻蜓。
- **地形**：每块地是细分的起伏地面，朝海的一面是分层岩壁，沙滩是缓坡。地块按 4×4 格的区块合并，放一块地只重算它和 6 个邻居，并且分帧完成。
- **环境之间的过渡**（v0.8）：
  - 陆地和陆地：交界处的高度、颜色、地表起伏按“附近几块地的加权平均”算，两边算出来完全一样，没有台阶和接缝；每块地的范围按噪声进退，交界线是弯的。草地靠沙滩的一侧草变稀，沙滩靠草地的一侧长沙丘草；林子越往外树越稀越矮，草地靠林子的一侧长出灌木和小树苗；麦田边缘参差不齐、麦子越往外越矮，邻地也零星长出几株；山脚散着滚下来的碎石。
  - 陆地和海：海岸线按噪声进退（不再是直的六边形边）；岸边一圈草变稀、露出土和岩石；岸外有一圈浅水台地，深浅不一，有的地方浅成沙洲；岩岸脚下和浅滩里散落礁石，沙滩的潮线上有海藻、漂流木和贝壳。
  - 天和海、岛：地平线上一圈积云，跟着太阳变色、被雾气淡进天边；清晨日出前后海面上浮着一层薄雾，太阳升高后散掉；地面和海面上本来就有云影在走。
- **人的生活**（`src/hq/villagers.js`）：每个营地住三个人，营地和两圈内的田地、麦田、林子、沙滩、水边之间有踩出来的小路。村民按钟点作息：清晨起床在屋前活动，上午和下午沿小路去干活（种地弯腰、砍柴、海边捡东西、水边打水），中午和傍晚回营地围着火坐，夜里回屋睡觉；时间固定不动时隔一阵换个地方干活。营地附近有沙滩就有一条渔船，清晨划出去、下午回来，海鸥跟着船盘旋。
- **海洋**：Gerstner 波浪、折射、按深度吸收、岸边浪花；海面、浪花、海底和阴影都跟着镜头走，地图多大都一样。
- **生态**：按区块里的地块类型生成动物（森林的鹿和林鸟、草地的羊群和野兔、花草地的蝴蝶和蜜蜂、山上的山羊、渔港沙滩的螃蟹）；海里沿海岸分出珊瑚礁、海草床、巨藻林、礁岩带，外海有鱼群、海豚、鲸、海龟、水母，岛变大以后跟着重建。
- **跨环境的动物**（`src/hq/wildlife.js`）：沙滩潮间带的鹬群跟着浪进浪退小跑、低头啄食；白鹭在岸边浅水和池塘边涉水、伸颈啄鱼；燕鸥沿海岸巡飞、悬停、收翅扎进海里抓鱼再爬升，黄昏落到沙滩上歇着；蝙蝠黄昏和黎明从树冠里飞出来捉虫；近岸的鱼偶尔跃出水面，清晨和黄昏最多。
- **作息**：各物种按钟点活动——蝴蝶、蜜蜂、蜻蜓白天出来，夜里停在花上、芦苇上；林鸟清晨和傍晚最闹，夜里不飞；野兔和鹿晨昏最活跃、正午歇着；羊群夜里挤成一团；螃蟹、青蛙夜里和黄昏更活跃；野鸭夜里漂着睡；白鹭夜里缩颈单腿站着睡，鹬挤在沙滩高处。
- **昼夜**：默认跟随设备的现实时间，也可以固定或拖动；光照按小时连续变化（清晨、正午、午后、黄昏、夜晚之间平滑过渡），夜里营火、窗户和灯塔会亮。
- **放地块**：新地块从海里升起，溅起水花和涟漪；放置预览和最终地块是同一套几何。
- **美术主题**（v0.13，设置 → 画面 → 美术主题）：经典（低多边形手作风）/ 体素（树、灌木、椰子树、岩石、山峰、鹿、羊、山羊、兔子、螃蟹、野鸭、青蛙都是方块；山顶积雪、顶面是平的，山羊照样能跳）。切换后重新载入，存档不受影响。屿灵两套主题共用。
- **按需绘制**（v0.13）：树木远近分级（离镜头远的区块换成几十个三角面的简化树、不投影）；合批时只画镜头视野内、一定距离以内的动物；离镜头远的蝴蝶、蜜蜂、蜻蜓、林鸟不画。三者的距离都随“细节系数”变化，帧时间超标时更早切换。
- **稳帧的三件事**（v0.11，针对真机 718 万三角面、9.6 帧的数据）：
  - 草叶分级：草、花、麦穗的实例顺序是打乱的，近处全画，越远画得越少，镜头拉远时整体再减（同一场景的峰值三角面约为原来的三成）。
  - 细节调节：按最近的平均帧时间自动调“细节系数”（0.3–1）——超过 36ms 就减草，低于 24ms 就加回来；分辨率和清晰度不动。性能测试结果里有“细节系数”。
  - 阴影缓存：阴影贴图每 3 帧重画一次，镜头挪动、时间变化、地块重建时立即重画。
  - 像素预算：渲染的总像素有上限（极致 240 万、高清 200 万、均衡 160 万、流畅 130 万），高分屏不再按原生 3 倍以上渲染，靠自适应锐化补清晰度。
- **自动画质**：一直在测，每 5 秒一个窗口，连续两个窗口低于 24 帧才降一档（极致 → 高清 → 均衡 → 流畅）；加载、演出、测速时不算。不会自动切到低多边形画面，中档仍然卡时提示手动切换。
- **加载页**：开局和换新岛时一次性生成地形、植被、海底、海洋生态、动物和界面缩略图，预编译着色器并在幕后渲染一帧；进入画面后不再边玩边生成。
- **帧节奏**：按时间间隔出帧（60/90/120Hz 屏幕都一样）；撑不住 60 帧时稳定锁在 30 帧；持续卡顿时自动降一档预设（不降分辨率，除非打开了动态分辨率）。
- **合批**：动物、海龟、海鸥按“同一部件”全岛合成一次绘制（`src/hq/batcher.js`）；山峰、道具、水面按区块合并；海底 32×32 一块；只有树、山、建筑和大动物的身体投影。同一场景每帧绘制从 521 次降到 264 次。
- **触控手感**（`src/camera.js`）：触摸预测（有上限防过冲）、松手速度用最近 100ms 轨迹拟合、双指手势按开头的动作分类（同向 = 转视角，反向 = 缩放）、以双指中点为中心缩放、拖出边界有阻力并回弹、旋转惯性、双击聚焦、双指抬起后 300ms 内不算点击。
- **省电模式**：触屏设备不操作 8 秒后降到 30 帧（设置里可以关）。
- **真机测速**：设置 → 性能测试。镜头绕岛转 20 秒，给出平均帧率、1% 低帧、帧时间分位数、绘制调用、三角面、显卡型号，结果可以复制。
- **显存回收**：离镜头 70 单位以外的区块释放网格和动物，回到附近时用缓存直接重建。

每一档都保持清晰（渲染精度不低于 1.5 倍，加自适应锐化），档位之间区别在渲染细节：

| 预设 | 渲染精度 | 阴影 | 环境光遮蔽 | 景深 | 泛光 | 抗锯齿 | 植被（草 / 花 / 树） | 生物 | 视距 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 极致（默认，同样张） | 2 | 4096 | 开 | 柔和 | 开 | 开 | 1 / 1 / 1 | 100% | 远 |
| 高清 | 2 | 2048 | 开 | 柔和 | 开 | 开 | 0.6 / 0.7 / 1 | 100% | 远 |
| 均衡 | 1.75 | 2048 | 关 | 关 | 开 | 关 | 0.35 / 0.45 / 0.8 | 70% | 中 |
| 流畅 | 1.5 | 1024 | 关 | 关 | 关 | 关 | 0.2 / 0.3 / 0.6 | 50% | 近 |
| 低多边形 | 1.5 | 1024 | — | 移轴 | — | — | — | — | — |

设置分“基础 / 画面 / 其他”三页。画面页可以逐项调：帧率（自动 / 30 / 60 / 高刷）、渲染精度、抗锯齿、锐化、动态分辨率（默认关，最低 85%）、阴影、环境光遮蔽、泛光、景深（关 / 柔和 / 移轴）、植被密度、生物数量、视距、显示帧率。改任一项就是“自定义”（存在 `settings.gfx`）；改植被或生物数量会走加载页重新生成。

在高画质和低多边形之间切换会先保存再重新载入。设备不支持高画质时自动用低多边形画面。

## 玩家素材的上传标准

完整规则在游戏里「装饰 → 我的素材 → 上传素材」可以看到，检查逻辑在 `src/ugc.js`。

- **图片**（PNG / JPG / WebP，2MB 以内，最短边 ≥ 32px）
  - 自动转成体素模型，颜色贴合到游戏的 30 个标准色。
  - 检查项：格式、分辨率、透明背景、留白、颜色数量、和游戏配色的差距、亮度与饱和度、杂点、比例、版权提示。
- **3D 模型**（GLB / 内嵌资源的 glTF / OBJ，5MB 以内）
  - 800 面以内为好，超过 2000 面不能使用。
  - 检查项：面数、贴图、颜色数量、配色差距、破面、原点与尺寸、比例、动画骨骼。
- **结果**：每一项给出「通过 / 建议修改 / 不能使用 / 已修复 / 提示」，写明检测到的具体情况和怎么改。能自动修复的（去背景、贴合配色、去杂点、删破面、忽略贴图）可以一键修复。风格分 ≥ 70 且没有「不能使用」才能加入。

## 高画质样张（v0.2 美术升级）

`npm run build:hq` 生成 `dist/hq.html`：一座完整渲染的展示岛，用来确定最终画面标准，确认后再接回游戏。

- **渲染管线**（`src/hq/pipeline.js`）：HDR 场景 → 屏幕空间环境光遮蔽 → 水面与软粒子 → 按深度计算的景深 → 泛光 → 调色（分离色调、暗角、轻微色差和颗粒）→ ACES 色调映射 → SMAA 抗锯齿
- **海洋**（`src/hq/ocean.js`）：Gerstner 波浪、程序生成的细节法线、天空反射与菲涅尔、屏幕空间折射、按深度吸收（浅滩透出海底）、逆光透射、岸边浪花与推向岸边的浪线、瀑布落水的白沫
- **地形**（`src/hq/terrain.js`）：细分的六边形地块（v0.8 起相邻地块平滑融合，没有接缝和土坎）、整圈分层岩壁、带沙纹的海底；材质里有程序化的颗粒、斑驳、岩层、裂隙、苔藓、水线湿痕和细节凹凸
- **植被**（`src/hq/vegetation.js`）：分层松树、带叶簇细节的阔叶树和灌木（逆光透射、风摆），5 万多根草叶、7 千多朵花、8 千株麦穗
- **其他**：岩峰与巨石、河流与两道瀑布、营火（火光闪烁 + 火星 + 炊烟）、灯塔（夜里光束）、海鸥、花粉光点、萤火虫、云影
- **生态（v0.3）**：
  - 海里：浅滩珊瑚礁（鹿角、脑、桌、海扇、海葵、海星、海胆）、海草床、断崖下的巨藻林；刺尾鲷、蓝刺尾鲷、沙丁鱼群、守着海葵的小丑鱼，海龟、海豚群、座头鲸、海月水母。
  - 岛上：森林的鹿和林鸟，牧场的羊群，花田的野兔和蝴蝶，岩山的山羊，河边和池塘的蜻蜓、野鸭、青蛙，新增的湿地池塘（睡莲、芦苇、香蒲）和沙滩（椰子树、螃蟹）。
- **物理**（`src/hq/waves.js`、`marine.js`、`fauna.js`）：
  - 波浪：海面、漂浮物浮力、水下轨道运动和水流共用一组 Gerstner 波，重力按场景比例取 0.98（1 单位 = 10 米）。
  - 水下运动：巨藻和海草随波浪轨道运动摆动；鱼群用群体算法，避开陆地、海底和海面，躲避海豚，并被水流带动；水母靠收缩推进、受阻力减速。
  - 跳跃与溅水：海豚跃出水面、兔子、青蛙、山羊的跳跃都按重力走抛物线；溅起的水滴受重力和空气阻力；入水点荡开涟漪。
  - 水下光影：浅水海底和珊瑚上有焦散光斑。
- **时段**：清晨、正午、午后、黄昏、夜晚；天空用大气散射模型，并实时烘成环境光照

地址参数：`?shot=hero|camp|falls|wild|reef|pond|beach|ocean|horizon|top`、`?time=morning|noon|afternoon|golden|night`、`?grass=0.5`（草的密度）、`?pr=1`（像素比上限）。

需要独立显卡或较新的手机才能流畅运行。生态规划、接入方式、性能预算和路线图见《屿见 生态多样性与接入计划》文档。

## 已知限制

- 广告是模拟的，存档和埋点只在本机。接入平台时替换 `src/services.js`。
- 音效和音乐是程序合成的，只在无头浏览器里验证过不报错，还需要真机试听。
- 自动化测试跑在软件渲染上，真机帧率、发热和内存需要在目标机型上实测。
- 玩家上传的素材和内置装饰仍是低多边形模型。
- 自由画布暂时只能放 4 种动物；鸟、蝴蝶、蜻蜓跟着地形自动出现。
