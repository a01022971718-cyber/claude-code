# 屿见 · MVP v0.1

一款治愈系 3D 低多边形海岛游戏。玩家从一块小岛出发，用三选一的地块卡把岛铺向远方的地标；每点亮一座地标，就有一位新同伴搬到岛上。地图没有边界，地标会一座接一座地生成下去。

手机浏览器横屏体验最好，竖屏也能玩。

## 怎么运行

```bash
npm install
npm run build          # 生成 dist/index.html（单文件，脚本已内联）
```

直接用浏览器打开 `dist/index.html` 即可，不需要服务器。开发时用 `node build.mjs --dev`，会生成不压缩、外链 `game.js` 的版本。

### 地址参数（测试用）

| 参数 | 作用 |
| --- | --- |
| `?debug=1` | 设置里出现调试按钮：加资源、快进 4 小时、进入下一天、加卡券 |
| `?fastads=1` | 模拟广告直接算看完 |
| `?q=high` / `mid` / `low` | 强制画质，关闭自动降档 |
| `?hour=18.5` | 固定岛上时间（小时，可带小数） |

## 玩法与系统

- **放地块**：手里 3 张卡，每张有价格。选卡 → 点亮起的格子预览（显示产出和相邻加成）→ 再点一次确认。地块从海里升起，结算资源。
- **地块**：草地、森林、山、菜园；接通风车后解锁麦田，接通灯塔后解锁渔港（只能放海边，带栈桥和渔船）。
- **收获**：森林、菜园、麦田、渔港可以点击收获，之后要等几小时重新长好，离线也计时。
- **地标与同伴**：风车（磨坊主阿穗）→ 灯塔（守塔人老汀）→ 钟楼（敲钟人小满）→ 之后是不断生成的远方地标和旅人。每座地标让资源上限 +10。
- **目标**：12 个主线目标兼做新手教学，做完后自动生成长期目标（接通下一座地标、岛屿规模、累计收获、委托）。
- **每日内容**：同伴委托（每天凌晨 4:00 刷新 3 个）、漂来的补给箱、作物重新生长。
- **激励视频（模拟）**：换牌、委托奖励翻倍、全岛立即长好。只做加成，资源用光时会免费送一张卡，不靠广告解围。
- **装饰**：16 种内置装饰，可以摆放、旋转、移动、收起、撤销。
- **玩家素材**：上传图片或低模，自动按标准检查、给出修改方法、一键修复，通过后转换成游戏风格的模型摆到岛上（见下）。
- **拍照**：隐藏界面，拖动构图，可以调时间拍黄昏和夜景。
- **存档与埋点**：自动存在本机浏览器；关键事件记录在本机，设置里可以查看和复制。

## 实时渲染

- **昼夜**：默认跟随设备的现实时间；可以在左上角时间里固定成清晨、正午、午后、黄昏、夜晚，或拖动滑块。
- **夜晚**：窗户、灯笼、灯室会发光，灯塔光束更明显。
- **后期**：移轴景深（微缩模型感）、泛光、调色、暗角。
- **场景**：风吹树和麦子摇摆，云影从岛和海面上掠过，海面有浅滩渐变、岸边白浪、一圈圈推向岸边的波纹和阳光碎闪。
- **自动画质**：开局后测 4 秒帧率，太低就从高降到中、再降到低。

| 画质 | 像素比上限 | 阴影 | 后期 | 抗锯齿 |
| --- | --- | --- | --- | --- |
| 高 | 2 | 2048 | 移轴 + 泛光 + 调色 | 4× |
| 中 | 1.5 | 1024 | 移轴 + 调色 | 2× |
| 低 | 1 | 无 | 无 | 浏览器默认 |

## 玩家素材的上传标准

完整规则在游戏里「装饰 → 我的素材 → 上传素材」可以看到，检查逻辑在 `src/ugc.js`。

- **图片**（PNG / JPG / WebP，2MB 以内，最短边 ≥ 32px）
  - 自动转成体素模型，颜色贴合到游戏的 30 个标准色。
  - 检查项：格式、分辨率、透明背景、留白、颜色数量、和游戏配色的差距、亮度与饱和度、杂点、比例、版权提示。
- **3D 模型**（GLB / 内嵌资源的 glTF / OBJ，5MB 以内）
  - 800 面以内为好，超过 2000 面不能使用。
  - 检查项：面数、贴图、颜色数量、配色差距、破面、原点与尺寸、比例、动画骨骼。
- **结果**：每一项给出「通过 / 建议修改 / 不能使用 / 已修复 / 提示」，写明检测到的具体情况和怎么改。能自动修复的（去背景、贴合配色、去杂点、删破面、忽略贴图）可以一键修复。风格分 ≥ 70 且没有「不能使用」才能加入。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 入口：输入、放置、收获、地标演出、每日内容、主循环 |
| `src/state.js` | 规则与存档（不依赖渲染） |
| `src/config.js` | 所有数值、文案、画质档位 |
| `src/hex.js` | 六边形坐标，无边界 |
| `src/tiles.js` | 地块几何：底座、岩壁、沙滩裙边、程序化装饰 |
| `src/world.js` | 地块按区块合并渲染、岸线距离场、选格标记 |
| `src/water.js` | 风格化海面着色器 |
| `src/sky.js` / `src/fx.js` / `src/post.js` / `src/stage.js` | 昼夜、着色器特效、后期处理、渲染器与灯光 |
| `src/actors.js` | 地标建筑、小人、渔船、补给箱、海鸥、粒子 |
| `src/decor.js` / `src/ugc.js` | 装饰模式；玩家素材的检查、修复、转换 |
| `src/ui.js` / `src/styles.css` | 界面 |
| `src/audio.js` | 程序合成的音效、海浪环境音和生成式背景音乐 |
| `src/services.js` | 存储、埋点、广告的平台抽象层：接微信或小红书小游戏时只换这一个文件 |
| `src/models/*.js` | 程序化低模：自然、建筑、装饰 |
| `tools/sheet.cjs` | 把一个模型文件里的所有模型渲染成一张预览图 |
| `tools/shot.cjs` | 打开游戏、执行脚本、截图，用于自动化测试 |

## 已知限制

- 广告是模拟的，存档和埋点只在本机。接入平台时替换 `src/services.js`。
- 音效和音乐是程序合成的，只在无头浏览器里验证过不报错，还需要真机试听。
- 自动化测试跑在软件渲染上，真机帧率需要在目标机型上实测。
