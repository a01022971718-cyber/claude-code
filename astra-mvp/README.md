# 具身精灵 MVP

手机网页原型，用来验证一个假设：用户亲眼看到"自己的工程产出驱动了精灵的行为"之后，会更愿意完成下一个实验，并回来改进它。

产品设计文档：<https://claude.ai/artifact/Ko6nfbrUcWWvgScnYKJcs1>

## 包含什么

- **星灵栖地**：插画背景 + 实时 3D 卡通渲染的六足精灵。没学会的部件是青色全息线框，学会后变成上色实体。
- **5 个单元**，每个单元先看概念卡和一道预测题，再做实验：
  1. 关节（正运动学）：转动 3 个关节，让足尖碰到目标
  2. 逆运动学：手指拖到哪，腿就算出角度跟到哪
  3. 步态：排出每条腿抬起的节奏，让它走完 1 米
  4. 稳定性：看裕度曲线，调参数让它走上 18° 的坡
  5. 自己学走路：调奖励权重，让它用进化策略自己试出步态
- **进化**：第 5 单元后触发，腿长和机身比例来自用户自己的步态参数。
- **工程年轮**：每次通过生成一页设定稿，三视图由同一个 3D 模型画出，规格表是用户的真实参数，可回放。
- 已完成的单元可以随时回去重调，新参数立刻生效并记入年轮。

## 和正式版的差别

- **稳定性是准静态模型，不是刚体物理仿真。** 判断依据是重心投影到支撑多边形边缘的距离（稳定裕度），没有模拟惯性、打滑和碰撞。正式版需要的物理仿真仍是最大的技术风险。
- **第 5 单元是进化策略**（16 代 × 12 个候选，搜索十来个步态参数），不是深度强化学习。界面里已如实说明。
- 进度只存在浏览器的 localStorage 里，没有账号和后端。
- 背景是程序绘制的占位画面，不是最终美术。

## 结构

```
src/
  spirit.js   精灵：运动学链（每条腿 3 个关节）、正逆运动学、几种外观
  gait.js     步态生成、稳定裕度、步态评分、进化策略
  stage.js    渲染舞台：栖地视图、工程视图、年轮三视图
  paint.js    程序绘制的草甸和全息背景
  core.js     进度存取、共用的界面和 3D 小工具
  home.js     栖地主场景、概念卡、进化、工程年轮
  exps.js     5 个实验
  content.js  5 个单元的文案
  style.css   样式（配色 v2：墨黑 / 冷白 / 霓虹红 / 电光黄 / 全息青）
  page.html   页面模板
build.mjs     打包成单个页面
```

## 构建

```
npm install
npm run build     # 生成 dist/page.html（发布用）和 dist/index.html（本地预览用）
npm run serve     # http://localhost:8770/index.html
```

three.js 从 CDN 加载（jsDelivr，固定版本 0.160.0），其余代码全部内联在页面里。

调试时可在浏览器控制台用 `window.__astra`：`__astra.state()` 查看进度，`__astra.go(__astra.screens.Exp3())` 直接跳到某个实验。
