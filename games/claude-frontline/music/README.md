# 背景音乐文件夹

把你的音乐文件（mp3 / ogg / wav）放在这里，然后在 `js/config.js` 里填写路径，例如：

```js
bgm: {
  menu:   { file: 'music/menu.mp3',   bpm: 96 },
  battle: { file: 'music/battle.mp3', bpm: 128 },
}
```

- `bpm` 是歌曲每分钟的拍数，用来让紫色像素动效跟着节拍跳动；不知道就填 100。
- 通过本地服务器打开游戏（如 `npx serve .`）时，游戏会实时分析音乐的低频能量来驱动动效；直接双击打开时浏览器限制读取本地文件，动效改用 `bpm` 计时。
- 更简单的方法：游戏内「设置 → 背景音乐 → 上传」，文件保存在浏览器里，不需要改任何代码。

可配置的页面：`menu`（主菜单/征程/成就/设置）、`academy`（学院/档案）、`lab`（实验室）、`battle`（战斗）、`boss`（Boss 战）、`victory`（胜利）、`defeat`（失败）。

请只使用你有权使用的音乐。
