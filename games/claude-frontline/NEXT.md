# 下一版本提醒（v6 待办）

> 开始 v6 时先过一遍这张表。前一部分是你在 v5 明确要求「下一版本提醒我」的事；后面是之前延续下来、还没完成的事。

## v5 你要求下一版提醒的

1. **沉浸模式 UI 大幅度调整**。
2. **主角「造乐」的碎片获取渠道**：v5 只定了「特殊渠道（高等级 VIP、限时活动）」，具体怎么拿、要多少片，下一版补足。
3. **活动获得**（英雄碎片的活动渠道）：v5 没做。
4. **界面 UI 继续优化**（参考王者荣耀、王者万象棋）。
5. **说台词时的标志性动作与表演效果**：v5 已经有配音和随机台词，动作与表演下一版做。

## 需要你决定的

6. **第七章掉「狂想（Grok）」碎片，但狂想是开局英雄**：现在多出来的碎片会自动换成晶片（每片 40）。要不要改成别的英雄，或者给重复碎片新的用途（例如英雄升星）？
7. **X-S 的形象侵权风险**：橙色像素小家伙和 Anthropic 的吉祥物很像，私下玩没问题，公开发布前需要重新设计（详见 `design/03-compliance.md`）。
8. **主标题设计稿的来源**：如果《造月之路》的标题图是用 AI 工具生成的，确认该工具允许商用。

## 之前版本延续下来的

9. **关卡奖励的详细规则**（v3 起）：掉落表、首通 / 重复 / 星级完整换算。
10. **英雄与法宝获取的详细规则**（v3 起）：v5 已经定了章节掉落与商城，还差法宝是否分等级、重复碎片的长期用途。
11. **活动副本 / 精英副本**：按你的要求放在三个版本以后（约 v6–v7）。
12. **难度微调**：第三章起是新加的 D15–35，需要你实际体验后再调。
13. **电路工坊**：v5 先做了高中 → 大学的 10 个实验，你看过效果后再决定下一步（更多实验、电子元件、和发电厂 / 主城养成的联动）。
