# 实验室 · 具身智能：造一台机器人——课程设计（v9.4）

> 主创要求：在实验室加一个「具身智能机器人制作全流程」功能，把六个阶段全部拆成「能玩、能学」的关卡；要有像电路图一样的组装闯关（硬件 + 软件）；按高中学历、零基础来教，难度适中，由浅入深、由点到线到面到体；并补充主创没想到的硬件和软件。
> 代码：`js/embodied-data.js`（课程数据，本文的表格由它生成）、`js/embodied.js`（玩法引擎和界面）。界面规则见 UI 宪法第 27 章 27.12–27.13，难度规则见关卡难度宪法第 14 章。

## 一、主线：造出「拾光号」

拾光号是一台移动操作机器人，由轮式底盘、6 自由度机械臂、头部深度相机和麦克风阵列组成。

它的任务是：听到「把桌上的杯子拿给我」，就走到桌边、找到杯子、抓起来、递到人手里。

为什么不做人形？这是按主创给的流程里的建议：新手先选结构简单的形态，避开双足平衡和全身协调的高门槛。

## 二、教法

1. **每关三步：学 → 练 → 考。**
   - 学：2–3 张知识卡。每张先讲清一个道理，再「打个比方」，比方全部来自日常生活。
   - 练：玩一种玩法。
   - 考：部分关卡有 1 道小测。
2. **点 → 线 → 面 → 体。** 每关都标了层级，难度沿这个顺序往上走。
   - 点：认识一个零件或一个概念。
   - 线：把几个零件连成一条链。
   - 面：搭出一个完整的子系统。
   - 体：合成整台机器人，跑通整个闭环。
3. **按顺序解锁。** 上一关通关，下一关才开，保证层层递进。体验模式下全部打开。
4. **难度适中：错了先讲道理，不直接给答案。**
   - 接错线、排错顺序都会说明为什么错，并计一次失误。
   - 「提示」会直接点出一步，同样计一次失误。
   - 同一关失败 4 次后，才出现「看答案」。
   - 星级：零失误 3 星；失误 + 提示不超过 2 次 2 星；其余 1 星；看了答案 1 星。
5. **数学只用高中知识。** 用到的有：力矩 = 力 × 力臂、功率 × 时间 = 能量、三角函数（运动学）、平移和旋转（手眼标定）、百分比与指数衰减（数据配比和平滑）。

## 三、六种玩法

| 玩法 | 怎么玩 | 用在哪里 |
|---|---|---|
| 接线（电路图式） | 零件是方块，接口是彩色圆点，颜色就是类型：24V / 12V / 5V、CAN / USB / 网口 / 串口 / I²C、图像 / 位姿 / 音频…… 点一个口再点另一个口就连上，也可以按住拖过去。类型不对接不上，系统会解释原因（比如「电压不一样会烧坏」）。点「检查」时，接错的线标红，并告诉你它本该连到哪。竖屏时整张图自动转成从上到下排。 | 电源、通信总线、URDF 骨架、ROS 2 节点、导航、语音、VLA、部署架构、毕业全链路 |
| 组装 · 工序 | 按先后顺序把零件或步骤点进去，里面混了陷阱卡（不属于这道工序的零件、危险操作）。 | 关节模组、整机总装、烧录与零位标定、软件分层、数据飞轮、全流程 |
| 分类 | 把卡片放进它属于的类别。 | 执行器 / 传感器 / 计算 / 能源，LeRobot 数据字段 |
| 计算 · 调参 | 按条件选型或拖动滑块，实时看到指标是否达标；部分关卡带小画板（机械臂、时间轴、俯视图、波形）。 | 电机 + 减速器选型、电池、运动学、Sim2Sim、时间戳、仿真与真实数据配比、模型加速、手眼标定、动作平滑 |
| 选择 · 诊断 | 看数据、看曲线、看症状，找出原因。 | 需求与形态、模组测试、出厂测试、仿真参数、训练曲线、闭环调试、失败分析、安全 |
| 遥操作示教 | 拖动操纵夹爪：抓起杯子、送到人手。录 3 条「合格」的演示；动作太绕、太犹豫的不收。 | 数据采集 |

## 四、主创的六个阶段 → 37 关

### 序章 · 全流程

造机器人不是把「大脑」装进「身体」就完事，而是设计 → 制造 → 仿真 → 训练 → 部署 → 反馈，一圈一圈地转。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 0-1 | 机器人是怎么造出来的 | 体 | 组装 · 工序 + 小测 | 机器人 = 身体 + 感觉 + 大脑 + 能源；这门课怎么学：点 → 线 → 面 → 体；我们要造的机器人：拾光号 |

### 阶段一 · 需求定义与本体设计

动手之前先想清楚：机器人要解决什么任务，据此选形态（轮式底盘 + 机械臂、四足还是人形），再完成机械设计、导出 URDF，选好执行器、传感器和计算平台。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 1-1 | 它要干什么：需求与形态 | 点 | 选择 · 诊断 + 小测 | 先有需求，再有形态；四种常见形态；自由度（DoF） |
| 1-2 | 认识零件：动、感、想、电 | 点 | 分类 + 小测 | 执行器：让机器人「动」；传感器：让机器人「感觉」；计算平台：让机器人「想」 |
| 1-3 | 电机选型：算一算力矩 | 线 | 计算 · 调参 | 力矩 = 力 × 力臂；减速器：用速度换力气；安全系数与背隙 |
| 1-4 | 能源：算电池 | 线 | 计算 · 调参 + 小测 | 功率 × 时间 = 能量；电池的「容量」怎么换算；电池是很重的 |
| 1-5 | 传感器选型：给每件事配一双「眼睛」 | 线 | 接线（电路图式） | 一个传感器只擅长一件事；常见搭配 |
| 1-6 | 本体设计：画出 URDF 骨架 | 面 | 接线（电路图式） + 小测 | 从 3D 图纸到 URDF；link 和 joint；它是一棵树 |

### 阶段二 · 硬件制造与组装

把图纸变成实物，按「零件 → 模组 → 整机」制造：加工结构件、组装并测试关节模组（温度、扭矩、转速），整机总装后烧录固件，最后做老化测试和功能测试。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 2-1 | 零件怎么做出来 | 点 | 接线（电路图式） | 同一张图纸，五种做法；打样 vs 量产 |
| 2-2 | 组装一个关节模组 | 线 | 组装 · 工序 + 小测 | 一个关节就是一个小机器人；为什么顺序很重要 |
| 2-3 | 模组测试：哪个能出厂 | 线 | 选择 · 诊断 | 每个模组都要过三关；看数据，不看感觉 |
| 2-4 | 电源系统接线 | 面 | 接线（电路图式） + 小测 | 电压像水压，设备只吃自己那一档；急停开关：安全第一；配电板 |
| 2-5 | 通信接线：机器人里的公路 | 面 | 接线（电路图式） | 总线 = 设备之间的公路；CAN 可以「串」起来；大脑和脊髓分工 |
| 2-6 | 整机总装 | 体 | 组装 · 工序 + 小测 | 零件 → 模组 → 整机；从下往上、从里往外 |
| 2-7 | 烧录固件与零位标定 | 线 | 组装 · 工序 | 固件：硬件里的「本能」；零位标定 |
| 2-8 | 出厂测试：老化与功能 | 面 | 选择 · 诊断 | 老化测试；功能测试 |

### 阶段三 · 系统与仿真环境搭建

搭软件底座和虚拟训练场：以 ROS 2 作为软件总线管理各模块通信；把 URDF 导入 Isaac Lab、MuJoCo 等仿真平台；先在仿真里验证控制算法（Sim2Sim），降低直接上真机的风险。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 3-1 | 软件分层：一层叠一层 | 点 | 组装 · 工序 | 软件也是一层层盖起来的；为什么要分层 |
| 3-2 | ROS 2：节点和话题 | 线 | 接线（电路图式） + 小测 | 节点 = 员工，话题 = 群聊频道；消息有格式；还有服务和动作 |
| 3-3 | 运动学：让手指到达目标 | 线 | 计算 · 调参 | 正运动学：角度 → 位置；逆运动学：位置 → 角度 |
| 3-4 | 导航：建图、定位、走过去 | 面 | 接线（电路图式） | 状态估计：我在哪；SLAM：边建图边定位；路径规划 |
| 3-5 | 语音系统：唤醒、听清、听懂、回答 | 面 | 接线（电路图式） | 语音是一条流水线；麦克风阵列还能听方向 |
| 3-6 | 导入仿真：物理参数对不对 | 线 | 选择 · 诊断 | 仿真 = 电脑里的物理世界；垃圾进，垃圾出 |
| 3-7 | Sim2Sim：换个仿真器再考一次 | 面 | 计算 · 调参 | 控制器也会「钻空子」；Sim2Sim 和域随机化 |

### 阶段四 · 数据采集与模型训练

给机器人「注入智能」：用遥操作采集专家演示（主从臂、VR、动捕手套），同步时间戳并转成 LeRobot 等标准格式；用仿真 + 真实数据混合训练（例如约 70 个仿真回合搭配 10–20 个真实回合）；在 GR00T、π0.5 等 VLA 模型上微调，学会把语言指令和视觉画面直接映射成动作。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 4-1 | 遥操作：示范给它看 | 点 | 遥操作示教 | 模仿学习：先看人怎么做；三种遥操作方式；数据质量比数量重要 |
| 4-2 | 时间戳对齐 | 线 | 计算 · 调参 | 每条数据都要盖「时间章」；相机常常「慢半拍」 |
| 4-3 | 整理成标准数据集 | 线 | 分类 | LeRobot 数据格式；观测 vs 动作 |
| 4-4 | 仿真 + 真实：混合配比 | 线 | 计算 · 调参 | 仿真数据：便宜但「假」；真实数据：真但贵；混合训练 |
| 4-5 | VLA 模型：看 + 听 → 动 | 面 | 接线（电路图式） | VLA = 视觉 - 语言 - 动作；基础模型 + 微调；动作块 |
| 4-6 | 看懂训练曲线 | 面 | 选择 · 诊断 | 训练集和验证集；三种常见毛病 |

### 阶段五 · 仿真到现实的迁移部署

把训练好的策略（通常导出为 ONNX 等格式）部署到真机：常用 Server-Client 架构，边缘设备负责实时推理，底层控制器负责高频执行；真机运行后重点监控动作抖动、响应停顿，优化动作平滑和实时控制参数，完成 Sim2Real 跨越。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 5-1 | 模型导出与加速 | 线 | 计算 · 调参 | ONNX：模型的「通用格式」；TensorRT：给 Jetson 的「涡轮增压」；量化：用更少的位数存数字 |
| 5-2 | Server-Client 部署架构 | 面 | 接线（电路图式） | 三层「大脑」，三种速度；为什么不全放在服务器上 |
| 5-3 | 手眼标定：相机看到的 = 手够到的 | 线 | 计算 · 调参 | 每个东西都有自己的坐标系；手眼标定 |
| 5-4 | 动作平滑：不抖又不慢 | 线 | 计算 · 调参 | 抖动从哪来；平滑的代价是延迟 |
| 5-5 | 闭环调试：看症状找原因 | 面 | 选择 · 诊断 | 上了真机才会出现的问题 |

### 阶段六 · 测试与迭代

部署不是终点：真机运行中暴露的新问题（感知盲区、特定物体抓取失败）形成反馈，驱动补充采集针对性数据、重新训练、再次部署，形成持续迭代的闭环。

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 6-1 | 失败分析：缺什么补什么 | 面 | 选择 · 诊断 | 失败是最值钱的数据；针对性补数据 |
| 6-2 | 安全：最后一道防线 | 面 | 选择 · 诊断 | 安全是层层设防的；看门狗 |
| 6-3 | 数据飞轮 | 体 | 组装 · 工序 | 飞轮：越转越快；回归测试和灰度发布 |
| 6-4 | 毕业：一句话到一个动作 | 体 | 接线（电路图式） | 把所有的「面」合成「体」；这就是具身智能 |

## 六、诚实说明

- **数字是教学用的近似值。** 电机参数、功率、推理耗时、成功率模型都按真实量级设定，但做了简化，目的是让取舍的道理清楚；真实项目要按具体零件的规格书算。
- **「约 70 个仿真回合 + 10–20 个真实回合」只是一个例子。** 这是主创给的配比，游戏里把它当作「一种常见配法」，不是定律。具体比例要靠实验找。
- **工具和模型名是真实存在的。** SolidWorks、URDF、ROS 2、Isaac Lab、MuJoCo、LeRobot、GR00T、π0.5、ONNX、TensorRT、Jetson、Nav2 都是业界真实在用的东西。游戏只教它们是干什么的、在流程里处于哪一步，不需要你安装。
- **以后可以接着做：**
  - 四足、人形各出一条线；
  - 把接线关和主城电路工坊的真实电路求解器打通；
  - 加一个「自由搭建」沙盒。

## 七、怎么加一关

在 `js/embodied-data.js` 对应阶段的 `levels` 里加一项：写好 `learn` 知识卡，选一种 `kind`，填上那种玩法需要的数据（接线是 `nodes` + `edges`，工序是 `steps` + `extra`，以此类推）。

加完运行 `node tools/check-embodied.mjs`，它会检查接口类型对得上、每道题有且只有一个正确答案、调参有解。
