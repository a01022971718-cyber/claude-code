# 勇气手账 · 全局 AI 助手 · 扩展工坊 · AI 学徒——设计说明（v9.6）

> 主创要求（v9.6）：
> 1. 增加一个能增加信心的功能：提供情绪价值，鼓励我，让我充满斗志。
> 2. 增加一个全局的 AI 助手：辅助学习、写代码等等，把聊天框有的能力都给它，只不过 API 是自定义的，玩家可以写自己的 API 来调用不同模型。

## 二、勇气手账：鼓励要有证据

设计依据是心理学家班杜拉提出的「自我效能」（相信自己能做成某件事）的四个来源。主创没提到、但很关键的一点：**最能长信心的不是别人夸你，而是你亲手做成过**。所以手账把重点放在「证据」上。

| 来源 | 手账里对应的部分 |
|---|---|
| 亲身做成过（最有效） | **我的星空**：存档里真实做到的每件事是一颗星（通关的关、完成的实验、答对的题、AI 学徒的关、写下的小胜利）；同一条赛道通关的关连成星座（拾光座、云雀座……）；月亮按真实进度从新月长到满月。下面是「你已经做到了」清单和「从零到专家，你在哪一段」的水彩小路。 |
| 看到别人也做到了 | **他们也失败过**：9 个真实故事（SpaceX 前三次发射失败、2008 年马斯克两家公司差点没钱、黄仁勋在餐厅洗碗到创立英伟达、NV1 失败、2024 年斯坦福对谈、Facebook 的 Beacon 风波和上市后股价腰斩、任正非 43 岁创业、火星直升机机智号）。每个都写年份、出处和「和你有什么关系」。 |
| 别人的鼓励 | **今天**：选心情（斗志满满 / 还行 / 累了 / 焦虑 / 迷茫 / 卡住了），给一句具体的话 + 一个 10 分钟内能做完的最小行动按钮（做 1 道题、做一分钟呼吸、看星空、让 AI 导师陪你过一下……）。接了 API 的话，「让 AI 教练说几句」会引用你真实的进度。 |
| 身体和情绪状态 | **一分钟呼吸**（方块呼吸：吸 4 秒、停 4 秒、呼 4 秒、停 4 秒，做 4 轮）；累了就做最小的一步。 |

另外：

- **小胜利**：再小也算（看懂一个词、坚持 10 分钟、修好一个报错）。
- **这一周**：七个点，出现就点亮，**断了不清零**。
- **我为什么出发**：一句愿景，累的时候看一眼。
- **给未来的信**：写给一周、一个月、三个月或半年后的自己，到日子才能拆。
- **卡住急救**：具身智能关卡里第 3 次失误时，在提示条里附一句鼓励（不弹窗）。
- **不给经验**：情绪相关的操作都不发经验，避免为了奖励表演情绪。
- **安全底线**：手账写明求助渠道（全国统一心理援助热线 12356、希望 24 热线 400-161-9995，号码以官方公布为准）。

## 三、全局 AI 助手

### 能做什么（对照聊天软件）

- **对话**：多轮对话、流式输出（边生成边显示）、停止、重新回答、编辑后重发、复制、朗读、对话列表（本机保存、改名、删除、导出成 Markdown）。
- **附件**：图片（自动缩到长边 1568 像素）、文本 / 代码文件（300 KB 以内）、PDF（目前只有 Claude 接口能直接读）。
- **显示**：思考摘要、联网搜索的关键词和来源、Markdown（标题、列表、表格、引用、代码）。
- **代码**：一键复制；HTML / JS / SVG 一键在隔离沙盒里运行（读不到游戏存档和 Key）。
- **模组**：AI 写出的模组显示成卡片：校验结果、试玩、安装、让助手修正。

**五种模式**（系统提示词都写在 `js/ai.js`，完整文本见 `design/10-mod-spec.md` 附录）：

| 模式 | 做什么 |
|---|---|
| 🎓 学习导师 | 先问你懂到哪，一次讲一个点，讲完出小题；问答案时先给提示 |
| 💻 代码助手 | 写短小能跑的代码、讲每一行、看报错 |
| 🔥 鼓励教练 | 只引用你真实的进度鼓励你，最后给一个 10 分钟的行动 |
| 🧩 模组工匠 | 按模组说明书给游戏做新内容、新功能 |
| 💬 自由聊天 | 什么都可以问 |

**让助手了解我的进度**（可关）：把存档里的进度摘要附在系统提示词后面，包括军衔、经验、连续天数、答题、实验、具身智能各赛道进度、AI 学徒进度、今天的心情、已装模组、当前页面；**不含任何 Key**。

### Claude 接口用了哪些参数

按 Anthropic 官方 SDK 文档写在 `js/ai-claude.js`：

- 官方 TypeScript SDK 1.8.0，打包成浏览器单文件 `js/vendor/anthropic-sdk.min.js`，离线可用。重新打包：`bash tools/build-anthropic-sdk.sh`。
- 默认模型 Claude Opus 5.5；流式（`client.beta.messages.stream`，最后用 `finalMessage()`）；一次最多 64000 token，可以改。
- 当前一代模型用自适应思考，显示思考摘要（`thinking: {type: 'adaptive', display: 'summarized'}`）；深度用 `output_config.effort`：快速 low / 平衡 medium / 深入 high，默认平衡。
- 系统提示词开提示缓存（`cache_control`），进度摘要放在缓存之后，所以每次变化也不影响缓存。
- **拒答兜底（默认开着，告诉你一声）**：官方地址 + 支持的模型（Fable 5.2 / 5.1、Opus 5.5 / 5、Sonnet 5.5）会带 `fallbacks: 'default'`（beta `server-side-fallback-2026-07-01`）：安全分类器拒绝时，服务器自动换支持的模型接着答。不想要可以在接口设置里关掉；用第三方中转地址时自动不发。
- 联网搜索（可选）：Opus / Sonnet / Fable 用 `web_search_20260209`，其他模型用 `web_search_20250305`；搜索太久会以 `pause_turn` 暂停，原样发回让服务器接着做。
- 历史：Claude 的回复原样保存（含思考块和签名），同一对话继续时原样发回，不改。
- 不发 temperature（新版接口已移除采样参数）。
- 新版 SDK 用 `Authorization: Bearer` 带 Key。

### Key 放在哪、什么会发出去

| | 浏览器版 / 单文件 H5 | 安卓 APK |
|---|---|---|
| Key 存在哪 | 这台设备浏览器的本地存储（localStorage） | 安卓系统私有存储（SharedPreferences「ai_keys」），**网页里的脚本读不到** |
| 进不进存档 / 备份 | 不进游戏存档 | 不进游戏存档；不进系统备份和换机迁移（`android/res/xml/*_rules.xml`） |
| 请求怎么发 | 浏览器直接发（有的平台不允许网页直连，会报「连不上」） | 原生网络桥 XSNet 代发：不受跨域限制；只有 https（或本机地址）、并且主机名和保存 Key 时一致，才把占位符换成真的 Key |
| 谁能用这个桥 | — | 页面启动时第一个来要令牌的脚本（游戏主页面）；沙盒、iframe 拿不到令牌 |

发出去的只有：你这一轮发给所选平台的对话内容、附件、系统提示词，以及（勾选时）进度摘要。对话保存在本机 IndexedDB「zy-ai」，不上传。费用由平台按 token 收，游戏不经手。

## 四、扩展工坊：让 AI 一直给游戏加东西

### 流程

1. 你对 AI 助手（模组工匠）说想要什么，或者在扩展工坊点一种类型，改一句话发出去。
2. AI 按 `design/10-mod-spec.md` 里的模板，写一个 ```` ```zaoyue-mod ```` 代码块。
3. 聊天里自动显示成模组卡片，并当场校验；没通过就列出错误，点「让助手修正」把错误发回给 AI。
4. 校验通过：试玩（小游戏）、安装；脚本模组还要先看代码、勾选确认。
5. 装好后马上生效；可以关掉、卸载、导出成文件分享。

### 六种模组

| 类型 | 能做什么 | 安全措施 |
|---|---|---|
| 📚 知识包 | 新题目进学院题库（错题本照常记）、知识卡 | 显示时转义，写的 HTML 不会执行 |
| 🦾 课程包 | 具身智能实验室多一条赛道（选择 / 分类 / 工序 / 接线），可登记同原理 | 安装时文字全部转义（只保留 `<b>`、`<br>`）；校验接线类型、正确答案唯一等 |
| 🌱 鼓励包 | 勇气手账里的鼓励话、真实故事 | 故事必须写出处，并标「未经官方核实」 |
| 🎨 水彩小游戏 | 任意小游戏，自带水彩工具包 ZYWC 和接口 ZY | 隔离沙盒（只有 allow-scripts），读不到存档和 Key；内容安全策略禁止联网；经验每天一次 |
| ⚙️ 脚本模组 | 改游戏的任何功能 | 安装前看代码 + 勾选确认；随时关掉；?safe=1 安全模式；上次启动卡住会自动进安全模式 |
| 📝 改动提案 | 需要改源代码的大改动 | 只保存、导出成 Markdown，交给开发工具（例如 Claude Code）去改 |

## 五、AI 学徒：用 AI 之前先懂 AI

| 关 | 名称 | 层级 | 玩法 | 学到什么 |
|---|---|---|---|---|
| 1 | 接龙机 | 点 | 拖温度滑块，看水彩概率柱怎么变，两轮目标（要稳 / 要有创意） | 大模型是「猜下一个词」；温度 |
| 2 | 上下文背包 | 线 | 一句句放进背包，满了最早的掉出去；它忘了猫叫什么，选办法 | Token、上下文窗口、压缩摘要 / 长期记忆 / 大背包 |
| 3 | 寄一封信给 AI | 线 | 把地址、Key、模型、内容放到信封上对的位置（有陷阱）；看真实请求；接了 API 可以真的寄一封；看懂 401 / 404 / 429 | API、Key、请求和回复、状态码、收费 |
| 4 | 好提示词 | 面 | 把句子分进角色 / 任务 / 背景 / 格式 / 例子；两段提示词选更好的 | 提示词五要素 |
| 5 | AI 也会编 | 面 | 点出 AI 回答里编造的两处；把东西分成「可以发 / 不要发」 | 幻觉、核实、隐私 |
| 6 | 让 AI 帮你写代码 | 面 | 真的运行 AI 写的有 bug 的代码（显示 011），点出错的那一行，再运行修好的 | 运行、观察、找 bug、怎么描述 bug |
| 7 | 做你的第一个模组 | 体 | 填一道题，实时生成模组 JSON，校验、安装，题目进学院题库 | 模组模板、校验，以后让 AI 照做 |

## 六、帮你补全的（主创没提到、但用 AI 必须知道的）

- **钱**：API 按 token 收费；先用平台的免费额度练手；图片、长文件、联网搜索更贵。
- **Key**：等于钱包钥匙；不发给任何人、不截图、不贴到网上；泄露就去平台删掉重建。
- **幻觉**：AI 会编书名、论文、链接、数字；重要的事去权威来源核实。
- **隐私**：身份证、银行卡、密码、Key、公司未公开资料不发给 AI。
- **上下文**：聊太长它会「忘」；一个话题聊完开新对话。
- **提示词**：角色、任务、背景、格式、例子。
- **本地模型**：电脑上可以用 Ollama 跑开源模型，免费、不联网，但需要电脑配置。
- **网络**：浏览器里有的平台不允许网页直连；安卓版走原生网络就没有这个限制。
- **心理健康**：长期低落、失眠，或者有伤害自己的念头，告诉身边的人，打热线。

## 七、诚实说明

- **没用真实 Key 测过**：这个环境里没有任何平台的 API Key。所有 AI 测试都是用和官方格式一致的假回复做的（拦截请求，检查 SDK 真正发出的参数和流式解析）。第一次用真 Key 时，先点「测试连接」。
- **安卓原生网络桥只编译通过，没在真机上跑过**：这里没有安卓模拟器。浏览器版的同一套逻辑测过。如果安卓上连不上，先在设置里换「兼容接口」试一下，或者告诉我报错文字。
- **预设的默认模型名会过时**：平台经常更新，以平台文档为准，用「测试连接」「获取模型列表」确认。
- **脚本模组是真的能改游戏**：所以要看代码、勾选确认。浏览器版里，脚本模组技术上能读到本机保存的 Key（安卓版读不到）；这一点设置页和安装确认框都写了。
- **「AI 参与所有功能的修改」的边界**：运行时能加的是内容（题目、课程、鼓励、小游戏）和脚本模组能改的功能；要改游戏本身的代码结构（例如战斗引擎），AI 写的是「改动提案」，导出后交给开发工具去改，再重新打包。
- **故事和数字**：「他们也失败过」只写公开报道的事实，细节以原始出处为准；AI 学徒里的概率、Token 数是教学示意。

## 八、怎么继续扩展

- **让 AI 做**：AI 助手 → 模组工匠，说你想要什么。
- **自己写**：扩展工坊 → 选类型 → 看模板 → 粘贴 JSON 安装。
- **改说明书**：模板和规则在 `js/mods.js`（`TEMPLATES`、`spec()`、`validate()`），改完重新导出 `design/10-mod-spec.md`。
- **改画风**：`js/watercolor.js` 的色卡和画法，UI 宪法第 28 章同步增补。
