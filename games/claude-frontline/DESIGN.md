# X-S战线 · 造物者之路 —— 设计说明（精简版 v2）

> v1 由「Claude战线」的原始描述精简而来；v2 改名 X-S，增加英雄、四种玩法与两份美术宪法。
> 视觉细则见 `art/01-typography-constitution.md`（字体）与 `art/02-game-ui-constitution.md`（界面）。

## 0. 原描述的问题（v1 的改动依据）

| 问题 | 表现 | 处理 |
|---|---|---|
| 一整段话、无层级 | 视觉、布局、操作、模式、配色混在一起 | 拆成小节，每节只说一件事 |
| 顶栏过载 | 约 16 个元素挤在一条 | v2 进一步改为四角分布，战斗 UI ≤ 18% |
| 浮层过多 | 目标、通讯、Boss 条、toast、触屏按钮同时出现 | 目标折叠成一行，通讯自动隐藏 |
| 按钮过密 | 建造 7 个 + 指令 6 个 | v2 取消底部按钮区，改为点击化操作与环形菜单 |
| 缺少核心目标 | 只有 RTS，没有学习与成长 | 学习 = 经济与科技引擎，战斗 = 检验场 |

## 1. 一句话定位

**你在现实里学到、做到的东西，会变成战场上的力量。** 品牌 X-S：新生 · 向上 · 探索未知。

## 2. 核心循环

```
学院 / 实验室（知识 30% · 实操 70%）─→ 经验、解锁、战斗加成、学习加速
        ↑                                              ↓
   结算复盘 + 成就  ←── 快速 / 沉浸 / 征程 / 主城入侵 ──→ 主城资源 → 主城科技 → 全模式加成
```

## 3. 界面

1. **大厅**（王者式功能枢纽）：左上字标与个人信息，右上资源与设置，中央展示主英雄（可切换、点击演奏），右侧透视倾斜的玩法入口（快速 / 沉浸 / 征程 / 主城），底部导航。
2. **英雄**：图鉴 + 英雄档案（档案、技能、专属、乐器与配色四个标签页，可试听主题曲）。
3. **征程**：5 关战役、沉浸模式、3 档遭遇战。
4. **学院 / 实验室 / 成长档案 / 成就 / 设置 / 说明**。
5. **主城**：建造、升级、收取、加速、入侵。

## 4. 战斗界面（UI ≤ 18%，四角布局）

- 左上：资源、人口（沉浸模式）、双方主脑耐久；通讯框在其下方，自动隐藏。
- 顶部中间：波次或昼夜计时，任务目标一行（点击展开）。
- 右上：研究、暂停、速度、小地图开关、菜单；小地图（手机默认收起）。
- 左下：建造、全军、选中信息条。
- 右下：物品栏（沉浸）、英雄头像（耐久环）、Q / W / R 技能。
- 选中信息改为单位头顶的浮动名牌；建筑操作改为绕在建筑周围的环形菜单。

## 5. 操作（点一下就完成）

点选中 · 点地面移动（沿途自动攻击）· 点敌人集火 · 点资源点建矿机 · 长按（右键）空地弹出环形建造菜单 · 长按后拖动框选 · 点建筑弹出训练环 · 技能按钮点按或拖动瞄准（电脑 Q/W/R 对准鼠标）· 双指（滚轮）缩放 · 拖动（右键）平移。第一关自动开始 10 步新手教程。

## 6. 英雄

X-S 原创主角 + 中美各 4 位，灵感来自知名 AI 大模型的公开特点，均为原创形象。每位英雄有乐器、色板、主题曲（固定动机）、像素形象与演奏动画、被动 + Q/W/R、专属小兵、专属建筑、世界观、性格、故事、口头禅。完整设定见 `art/03-heroes.md`。

## 7. 玩法

- **快速模式（90 秒）**：拖动移动、自动攻击、踩拍点屏「完美」、连击称号、三选一强化、FEVER、首领，结束一张成绩卡。
- **沉浸模式**：迷雾、野怪营地（夜晚入睡、脱离领地回营）、英雄等级与加点、物品与商店、攻防类型、人口维护费、三级科技、会扩张会撤退的 AI 对手、昼夜。
- **征程**：5 关战役 + 遭遇战。
- **主城**：大本营限制其他建筑的等级与数量，真实时间产出，学习加速，乱码入侵防守战，科技加成所有战斗。

## 8. 视觉与音乐

招牌动效「像素脉冲」：英雄色板的像素方格随节拍从角色处扩散，角色抱乐器演奏，乐器发声点飘出专属粒子。所有页眉、弹窗页眉、模式入口、大厅、主城地面和快速模式地面都使用它；全局 `--beat` 变量让按钮与面板一起呼吸；页面切换用像素擦除。音乐全部程序合成（9 种乐器），可替换为自定义音乐。

## 9. 技术

原生 HTML5 Canvas 2D + Web Audio API，零依赖、可离线；`node build.mjs` 打包单文件。
