# Claude战线 · 造物者之路 —— 设计说明（精简版）

## 0. 原描述的问题（为什么要改）

| 问题 | 表现 | 处理 |
|---|---|---|
| 一整段话、无层级 | 视觉、布局、操作、模式、配色混在一起，难以扫读和验收 | 拆成 7 个小节，每节只说一件事 |
| 顶栏过载 | 品牌+3资源+3产量+波次+倒计时+标签+2条耐久+2个计数+4个按钮 ≈ 16 个元素 | 顶栏只留「资源 · 波次 · 双方主脑」，其余收进菜单/选中面板 |
| 战场浮层过多 | 目标面板、通讯框、Boss条、toast、触屏按钮、确认栏可能同时出现 | 目标折叠成一行；通讯框自动隐藏；同一时刻最多 2 个浮层 |
| 底部按钮过密 | 建造 7 个 + 指令 6 个同时显示 | 「建造 / 指令」两个页签，选中单位时自动切到指令 |
| 缺少核心目标 | 描述只有 RTS，没有「学习与成长」 | 学习=经济与科技引擎，战斗=检验场（见第 2 节） |

## 1. 一句话定位

深色控制台风格的科幻即时战略 + 成长系统：**你在现实里学到、做到的东西，会变成战场上的资源、建筑和战力。**

## 2. 核心循环

```
学院/实验室（知识 30% · 实操 70%）→ 获得经验、解锁建筑与关卡、提升战斗加成
        ↑                                                  ↓
   结算复盘 + 成就  ←────────  战役 / 遭遇战（检验与反馈）
```

- **知识（30%）**：测验题，答错即讲解。
- **实操（70%）**：8 个可交互实验（梯度下降、感知机、PID 无人机、机器人编程、火箭方程、创业沙盘、代码挑战、像素工坊）+ 线下任务打卡（需写实践记录）。
- **德智体美 + 企业家**：成长雷达 6 维（德 · 智 · 体 · 美 · 实操 · 企业家），企业家情景决策取材于马斯克、扎克伯格、黄仁勋的真实经历。
- **配比引擎**：实时显示知识/实操比例，偏离 3:7 时推荐下一项任务。

## 3. 界面（5 个主页面）

1. **主菜单**：品牌（旋转橙色火花）+ 菜单条；悬停的菜单条播放紫色像素脉冲 + 弹吉他小人动效。
2. **征程**：5 关战役（第一行代码 → 守住上下文 → 原型机护送 → 制空权 → 终局决战），每关有目标和三星评价，解锁条件含实验；遭遇战 3 档难度。
3. **学院**：今日修炼 / 知识测验 / 线下任务 / 企业家修炼 / 学习路线。
4. **实验室**：8 个实操实验。
5. **成长档案**：配比、雷达图、领域熟练度、实践日志、存档导入导出。

另有：成就、设置（含每个页面的背景音乐）、玩法说明。

## 4. 战斗界面（3 个区域）

- **顶栏**：品牌 ｜ 晶片·语料·算力（数值 + 每秒产量）｜ 波次 + 倒计时 + 标签（如「空军首领」）｜ 我方/乱码主脑耐久 ｜ 暂停 · 速度 · 菜单
- **战场**：电路纹理 + 数据断崖；左上一行任务目标（可展开）；左下通讯框；Boss 出现时顶部血条；toast 提示
- **命令甲板**：小地图（橙=我方，粉=乱码）｜ 选中信息（名称、描述、耐久、属性、训练队列）｜ 建造/指令页签
  - 建造：矿机 1 · 炮塔 2 · 屏障 3 · 修复站 4 · 雷达站 5 · Agent 工坊 6 · 无人机空港 7
  - 指令：技能 · 攻击移动 A · 停止 S · 驻守 H · 推进主脑 G · 全选军队 Q

## 5. 操作

- 鼠标：左键选择/框选，右键移动/攻击，右键或中键拖拽平移，滚轮缩放，点小地图跳转
- 键盘：方向键平移，空格暂停，数字键建造，字母键指令（A/S/H/G/Q/C/R/E/K）
- 触屏：单指平移，双指缩放，浮动按钮「框选」「全军」，建造时底部出现确认栏
- 手机竖屏：显示「请横屏游玩」提示层，可选「旋转画面横屏游玩」或「仍然竖屏继续」

## 6. 视觉与音乐

- 配色：深空黑 `#0b0a12`、Claude 橙 `#d97757`、晶片金 `#e9b949`、语料青 `#3fd0c9`、算力紫 `#9b7bff`；乱码军团粉 `#ff4f9a` / 青 `#29e0e0`；文字米白 `#ede6d6`；数据用等宽字体
- 招牌动效：深紫底色 + 像素方格随节拍从角色处一圈圈亮起；像素小人抱紫色吉他扫弦、点头、眨眼，金色像素音符飘出（来自参考视频）
- 音乐：每个页面一首程序生成的吉他曲（菜单、学院、实验室、战斗、Boss、胜利、失败），视觉脉冲与节拍同步；可在设置里为任意页面上传自己的音乐，或在 `js/config.js` 里填文件路径

## 7. 技术

原生 HTML5 Canvas 2D + Web Audio API，零依赖、可离线、直接双击打开；`node build.mjs` 生成可分享的单文件版本。存档保存在浏览器本地，可导出 JSON 备份。
