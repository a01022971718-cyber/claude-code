# Claude战线 · 造物者之路

一款把「学习 AI × 具身智能 × 航空航天 × 创业」做成即时战略游戏的 H5 游戏。
**你在学院和实验室里学到、做到的东西，会变成战场上的资源、建筑和战力。**

精简后的设计说明见 [DESIGN.md](DESIGN.md)。

## 怎么玩

- **电脑**：双击 `index.html` 直接打开（Chrome / Edge / Safari 均可，不需要联网）。
- **手机 / 分享**：运行 `node build.mjs`，把生成的 `dist/claude-frontline.html` 发到手机上打开。横屏体验最好；竖屏时游戏会提示，也可以让它替你旋转画面。

第一次进入时点一下屏幕开启声音。

## 核心循环

| 你做的事 | 类型 | 战场上的效果 |
|---|---|---|
| 知识测验（78 题，答错有讲解） | 知识 30% | 起始晶片 + |
| 8 个交互实验（梯度下降、感知机、PID 无人机、机器人编程、火箭方程、创业沙盘、代码挑战、像素工坊） | 实操 70% | 算力产出 +，解锁雷达站 / 无人机空港 / 关卡 |
| 35 个线下实操任务（写代码、做纸飞机、采访用户、运动、练琴……需写实践记录） | 实操 | Claude 弦振伤害 +，解锁修复站 |
| 11 个企业家情景决策（马斯克、扎克伯格、黄仁勋的真实经历） | 实操（决策） | 创始人属性，解锁第 5 关 |
| 学习路线里程碑（真实世界的学习计划） | 实操 | 经验 |

「成长档案」会显示知识/实操配比（目标 3:7）、德智体美 + 实操 + 企业家六维雷达、领域熟练度和实践日志。

> 说明：游戏能把大目标拆成每天可执行的小步并给你反馈，但真正的成长发生在游戏之外。线下任务要真的去做。

## 战斗

- 战役 5 关：第一行代码 → 守住上下文 → 原型机护送 → 制空权 → 终局决战，每关有任务目标与三星评价。
- 遭遇战 3 档难度（随机地形）。
- 建筑：矿机、炮塔、屏障、修复站、雷达站、Agent 工坊、无人机空港。英雄 Claude 会弹吉他：R「弦振冲击」、E「灵感和弦」。
- 结算面板有兵力曲线和波次战损图。

操作说明在游戏「玩法说明」里。

## 换背景音乐

每个页面（主菜单、学院、实验室、战斗、Boss、胜利、失败）默认播放一首程序合成的吉他曲（Karplus-Strong 拨弦算法），紫色像素动效跟着节拍跳。

- 最简单：游戏内「设置 → 背景音乐」，为任意页面换曲风或上传自己的音乐。
- 打包分享：把文件放进 `music/`，在 `js/config.js` 里填写路径，详见 [music/README.md](music/README.md)。

## 修改内容

所有学习内容都在 `js/content.js`，格式直观，可以直接添加题目、线下任务和情景：

- 题目：`['ai', '题干', ['选项A', '选项B', '选项C', '选项D'], 正确下标, '讲解']`
- 线下任务：`['emb', '标题', '做法', '实践记录提示', 经验值, { shi: 1, zhi: 0.5 }]`

## 文件结构

```
index.html        页面骨架
css/style.css     样式
js/config.js      背景音乐与音量配置（可改）
js/core.js        工具、存档、提示、弹窗
js/audio.js       程序吉他音乐、音效、自定义音乐
js/pixelfx.js     紫色像素脉冲 + 弹吉他像素小人
js/content.js     学习内容库
js/progress.js    经验、3:7 配比、解锁、成就、战斗加成
js/labs.js        8 个实验
js/academy.js     学院、实验室列表、档案、成就页
js/levels.js      关卡与遭遇战
js/game.js        RTS 引擎（A* 寻路、流场、单位 AI、渲染）
js/ui.js          界面、战斗 HUD、输入、结算
build.mjs         打包成单文件
```

技术：原生 HTML5 Canvas 2D + Web Audio API，无第三方依赖。存档在浏览器本地（`localStorage`），可在「成长档案」导出/导入。
