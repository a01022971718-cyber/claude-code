# X-S 字体美术宪法 v1.1

> 适用于游戏内所有文字：品牌字标、标题、正文、数据、标签与动态文字。
> 本宪法的每一条都已落成可复用代码：`css/style.css`（字体类与令牌）和 `js/brand.js`（字标、标志、逐字上升）。
> 优先级：本宪法 > 单个页面的临时设计。需要例外时，先修订宪法，再改页面。

---

## 第 1 章 品牌寓意：X-S 是什么

| 元素 | 形 | 意 |
|---|---|---|
| **X** | 四芒星旋转 45°，正好是一个 X | **未知**（方程里的未知数 x）与**新星**（新生） |
| **S** | 从左下升到右上的 S 曲线 | **向上**：Sigmoid 学习曲线，也是火箭爬升的轨迹 |
| **-** | 一条短横线 | **地平线**：从未知到新生的分界，破晓从这里升起 |
| 色彩 | 紫夜 → 破晓橙金，加一束探索青 | 夜（未知）→ 日出（新生），青光是去探索的那束光 |

一句话：**在未知的紫夜里，一颗新星沿着 S 曲线向上，迎来破晓。**

## 第 2 章 从原「Claude 战线」字标继承的三条美感

旧字标里值得保留的，不是那个名字，而是它的构成方式。下面三条被定为字标的基因：

1. **双色分工**：拉丁品牌字着色，中文用米白。两部分永远不同时着色，也不同时使用白色。
2. **标志先行、粗重几何**：标志放在字前，高度约为字高的 1.15 倍；字重用 900（中文 800），轮廓干净有力，不加描边。
3. **像素与矢量并置**：标志和字是平滑的矢量，旁边的角色和动效是像素。这种「锐利的字 + 颗粒的画」的反差就是风格本身。

## 第 3 章 字标规范

```
[标志]  X-S  战线
  │      │    └─ 中文：米白 #ede6d6 · 字重 800 · 字距 +0.06em
  │      └────── 拉丁：破晓渐变（下 #ff7a45 → 中 #ffb14a → 上 #ffe08a）· 字重 900 · 字距 +0.02em
  └───────────── 标志：高度 1.15em · 与字的间距 0.32em · 节拍时放大 ≤ 12%
```

- **渐变方向必须自下而上**（0°），象征「向上」。禁止左右渐变。
- **投影**：`0 3px 0 rgba(10,6,30,.65)` 的像素硬投影 + 英雄主光色柔光（18px，强度 0.25 + 节拍 × 0.35）。
- **最小尺寸**：字标 ≥ 20px；小于 20px 只用标志，不用字。
- **安全区**：四周至少留出 0.5 倍字高的空白。

**禁止**
- 中文也使用渐变或彩色；
- 拉伸、倾斜、加描边或外发光框；
- 把标志放到字后面，或单独旋转标志；
- 在浅色背景上使用破晓渐变（对比不足）。浅色背景改用深紫 `#1e1636` 单色字标。

## 第 4 章 字体栈（离线优先，不依赖网络字体）

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 中文 `--sans` | PingFang SC → HarmonyOS Sans SC → MiSans → Microsoft YaHei → Noto Sans SC → Hiragino Sans GB → system-ui | 所有中文 |
| 展示拉丁 `--display` | Avenir Next → Segoe UI Variable Display → Segoe UI → Helvetica Neue → Arial | 字标「X-S」、英文标题 |
| 等宽 `--mono` | ui-monospace → SF Mono → JetBrains Mono → Cascadia Mono → Menlo → Consolas | 数字、计时、标签、代码 |

## 第 5 章 字号阶梯（1.25 倍，大三度）

| 令牌 | px | 字重 | 行高 | 字距 | 用途 |
|---|---|---|---|---|---|
| `--fs-5xl` / `.t-display` | 49 | 900 | 1.05 | +0.04em | 大厅英雄名、结算评级 |
| `--fs-4xl` | 39 | 900 | 1.1 | +0.08em | 大厅英雄名（桌面） |
| `--fs-3xl` / `.t-h1` | 31 | 800 | 1.15 | +0.05em | 页面主标题、英雄档案名 |
| `--fs-2xl` | 25 | 800 | 1.2 | +0.04em | 模式入口大字 |
| `--fs-xl` / `.t-h2` | 20 | 800 | 1.25 | +0.04em | 页眉条标题、弹窗标题 |
| `--fs-lg` / `.t-h3` | 16 | 700 | 1.3 | 0 | 卡片标题、引语 |
| `--fs-md` / `.t-body` | 14 | 400 | 1.7 | 0 | 正文 |
| `--fs-sm` / `.t-cap` | 12 | 400 | 1.6 | 0 | 说明、次要信息 |
| `--fs-xs` / `.t-tag` | 11 | 400 | 1.4 | +0.14em | 英文标签（全大写、等宽） |

- 中文正文行高 1.7：中文字面饱满，行距要比拉丁更宽松。
- 同一屏最多同时出现 **4 个**字号层级。

## 第 6 章 中英混排

1. 中文与拉丁字母、数字之间留一个空格（或 0.25em）：「主脑 T2」「Lv 6」。
2. **英文标签**全部大写、等宽、字距 +0.14em，使用英雄点缀色：`MISSION 01`、`X-S ORIGINAL`。
3. **引语与口头禅**用「」，书名号着英雄点缀色（`.t-quote`）。
4. 中文标点不挤压；数字后的单位用全角空格以外的普通空格分开（「90 秒」）。

---

## 第 7 章 数字

- 所有数值使用等宽数字（`font-variant-numeric: tabular-nums`），保证跳动时不抖。
- 资源数字跟随资源色：晶片金 `#e9b949`、语料青 `#3fd0c9`、算力紫 `#9b7bff`。
- 时间统一 `m:ss`；超过 1 小时用「X 时 Y 分」。
- 大数字超过 1 万缩写为 `12.3k`；分数结算时完整显示并加千分位。

## 第 8 章 色彩与可读性（实测对比度，背景为深空黑 `#0b0a12`）

| 文字色 | 对比度 | 允许用途 |
|---|---|---|
| 米白 `#ede6d6` | 15.8 : 1 | 正文、标题（首选） |
| 暗灰 `--dim #9d96ad` | 6.9 : 1 | 次要说明、说明文字 |
| 弱灰 `--mute #6c6680` | 3.6 : 1 | **仅限** ≥ 14px 粗体或装饰性文字，不得用于正文 |
| 破晓金 `#ffb14a` | 10.9 : 1 | 强调、字标 |
| 主按钮文字 `#2a1206` 在 `#ffb14a` 上 | 9.8 : 1 | 主按钮 |
| 白字在紫夜 `#33207a` 上 | 12.9 : 1 | 页眉条标题 |

规则：正文 ≥ 4.5 : 1，大字（≥ 18px 或 14px 粗体）≥ 3 : 1。英雄主光色只用于标题、名字和强调，不用于大段正文。

## 第 9 章 文字动效：「向上」

- **逐字上升**（`.t-rise` / `CF.Brand.rise()`）：每个字从下方 6px 处淡入上升，时长 320ms，逐字间隔 40ms，缓动 `cubic-bezier(.2,.8,.2,1)`。用于英雄名、结算标题等「登场」时刻，同一屏只用一次。
- **节拍呼吸**：字标的标志、光晕随 `--beat`（0–1）变化，缩放上限 12%。**文字本身永不随节拍抖动**，保证可读。
- **飘字**（伤害、拾取、收取）：上升 40–46px，0.9–1.1 秒内淡出；暴击用黄 `#fff35c` 并放大 1.4 倍，再回弹。
- **减少动效**：系统开启「减少动态效果」或在设置中开启「减少动效」时，以上动画全部关闭，只保留静态样式。

## 第 10 章 英雄字色

- 英雄名用该英雄的**主光色**（见《游戏界面视觉宪法》第 2 章色板）。
- 英雄主光色背景上的文字一律用白色或米白，不用同色系。
- 口头禅前后的「」用英雄点缀色，正文仍为米白。

## 第 11 章 可复用组件

| 类 / 函数 | 作用 |
|---|---|
| `CF.Brand.wordmark('战线')` | 生成完整字标（标志 + X-S + 中文），可换中文部分 |
| `CF.Brand.emblem()` | 只生成标志 SVG |
| `CF.Brand.rise('文字')` | 生成逐字上升的文字 |
| `.wm` `.wm-mark` `.wm-latin` `.wm-cjk` `.wm-shadow` | 字标的结构与投影 |
| `.t-display` `.t-h1` `.t-h2` `.t-h3` `.t-body` `.t-cap` | 字号层级 |
| `.t-tag` `.t-num` `.t-quote` `.accent` | 标签、数字、引语、点缀色 |

示例：

```html
<div class="lob-logo"><!-- JS: el.innerHTML = CF.Brand.wordmark('战线') --></div>
<div class="t-tag">MISSION 01</div>
<h1 class="t-h1">第一行代码</h1>
<p class="t-quote">新生，向上，去未知的地方！</p>
<b class="t-num c-chip">1,280</b>
```

## 第 12 章 审核清单

- [ ] 字标只有拉丁部分着色？渐变是自下而上？
- [ ] 同一屏字号层级 ≤ 4？
- [ ] 所有数字都是等宽？资源数字用了资源色？
- [ ] 正文对比度 ≥ 4.5 : 1？没有把 `--mute` 用在正文？
- [ ] 中英文之间留了空格？英文标签是大写等宽？
- [ ] 文字没有随节拍抖动？「减少动效」下动画都关闭了？

## 第 13 章 主标题 Key Logo（v1.1 增补）

> 第 3 章的字标继续用于页眉、弹窗等小尺寸场合；大厅、启动页、宣传图使用本章的主标题。参考王者荣耀、QQ 飞车等成熟游戏标题的做法：**有厚度、有材质、有副标、有动势**，同时第 2、3 章的规则全部保留。

```
        ·  ·          （上升的像素火花）
  ✦  X-S  战线        ← 标志 + 拉丁（破晓渐变 + 顶面受光 + 扫光） + 中文（米白）
  ╲________________   ← 像素挤出厚度（6 层紫夜，自上而下渐深）
 ━━━━━━━━━━━━━━━━━━   ← 地平线（探索青），破晓辉光从这里升起
        ▛ 造物者之路 ▜  ← 副标飘带（像素台阶边角 + 破晓金顶边）
```

| 要素 | 规则 | 与原宪法的关系 |
|---|---|---|
| 矢量字形 | 「X-S」「战线」等字用 Noto Sans SC Black / Noto Sans Black（SIL OFL 1.1）的轮廓重排，不依赖手机系统字体 | 第 2 章「粗重几何」的落实 |
| 字号关系 | 拉丁大写高度 ≈ 中文字面高度 × 0.9；标志可见高度 ≈ 中文字面高度 × 0.75 | 补充第 3 章 |
| 挤出厚度 | 6 层、每层下移 0.9% 字高，颜色 `#4a2fa0` → `#130b30` 逐层加深；只向正下方 | 第 3 章像素硬投影的延伸（仍是投影，不是描边） |
| 顶面受光 | 拉丁上部 19% 叠一层 `#fff6e0` 0.55 → 0 的高光 | 渐变仍自下而上 |
| 扫光 | 白色光带每 6 秒**自下而上**扫过拉丁与标志一次 | 呼应「向上」；减少动效时关闭 |
| 中文 | 仍为米白 `#ede6d6` 单色，只有厚度，没有渐变与高光 | 第 2 章双色分工不变 |
| 地平线 | 字底下方一条探索青细线，两端渐隐；后方破晓辉光（半椭圆）随节拍增亮 | 第 1 章「-」= 地平线的视觉化 |
| 上升火花 | 6 个像素方块（破晓金 / 探索青）缓慢上升淡出 | 像素与矢量并置 |
| 副标飘带 | 深紫底 + 像素台阶边角 + 破晓金顶边 + 两端菱形；文字米白，字距 0.5em | 新增 |

- 中文部分可替换：`CF.Brand.keyLogo({ cjk: '战线', sub: '造物者之路' })`，或在 `js/config.js` 改 `title`。字形库里没有的字会自动退回系统字体；需要新字时运行 `tools/gen-brand-glyphs.py` 重新导出。
- **禁止**：给主标题加描边或外发光框、倾斜或拉伸字形、把扫光改成左右方向、给中文上色。
- 最小使用尺寸：主标题高度 ≥ 40px；更小时改用第 3 章字标。
